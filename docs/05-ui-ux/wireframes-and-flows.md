3.2 خوارزمية البناء الديناميكي (منطق العرض)
text

function renderTemplateScreen(template, context):
    FOR field IN template.fields:
        IF field.visible_when AND NOT evaluateCondition(field.visible_when, current_values):
            CONTINUE  // إخفاء ديناميكي فوري (مثل items فقط عند inventory_mode=true)
        
        widget = FieldWidgetFactory.create(field.type)  // من كتالوج 0.6
        widget.bind(field.key, onChange: revalidateForm)
        renderWidget(widget)

    IF template.requires_contact.required OR hasContactField(template):
        renderContactPicker(allow_quick_add: template.requires_contact.allow_quick_add)

    renderPrimaryButton(
        label: "حفظ العملية",
        enabled: isFormValid(),
        onPress: () => executeTemplate(template.template_code, collectedValues)
    )
3.3 التحقق الفوري (Inline Validation) — تجربة مستخدم حرجة
القاعدة	وقت التنفيذ	مثال رسالة
validation من تعريف الحقل	عند كل تغيير (Debounced 300ms)	"المبلغ المدفوع أكبر من الإجمالي"
سقف الائتمان (من وحدة AR/AP)	عند اختيار العميل + تغيير المبلغ	تحذير أصفر غير مانع: "سيتجاوز حده المسموح بـ 5,000"
توازن القيد (نظري، خلفي)	عند الضغط على "حفظ" فقط	لا يظهر للمستخدم أصلًا — يُرفض بصمت ويُعاد توجيه المستخدم لتصحيح الحقل المعنيّ
3.4 زر "الوضع السريع" العائم
عندما allow_quick_mode = true (كما في sale_cash)، يظهر زر صغير أعلى الشاشة: "سريع ⚡" يُخفي كل الحقول الثانوية ويُبقي فقط (مبلغ + طريقة دفع) — تحقيقًا المباشر لمتطلب "وضع سريع بمبلغ فقط دون أصناف".
